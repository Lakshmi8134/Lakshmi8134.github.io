01
Policy-as-Code Governance Architecture for Safe LLM-Assisted Security Remediation
GitHub ↗

MSc thesis project. A governed architecture for using LLMs to assist with cloud security analysis and remediation recommendations, while keeping all infrastructure changes controlled through Policy-as-Code, CI/CD validation, and human approval workflows. GPT-5.1 generates Terraform HCL advisories; deterministic validation, risk classification, and human approval enforce every change.

Built
The full governance architecture — detection, LLM-assisted analysis, policy validation, and the human approval gate before any remediation is executed.
Principle
The LLM can assist with analysis and recommendations. It must not have direct, uncontrolled access to modify cloud infrastructure — every action passes through policy validation, governance controls, and approval.
Stack — Terraform · Azure Policy · Open Policy Agent (OPA) · Rego · Azure DevOps · CI/CD · Azure Functions · Microsoft Entra ID / Managed Identity · Azure Key Vault · Log Analytics · Application Insights
Detect → Analyse → Generate Recommendation → Validate → Human Approval → Controlled Remediation
